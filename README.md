# سامانه هوشمند آزمون‌ساز و تحلیل کنکور تستیونو (Testino)

نسخه: 0.1.8 | موتور ارزیابی، شبیه‌سازی و تحلیل تست‌های کارشناسی ارشد مدیریت

---

## ۱. معرفی موتور و سامانه تستیونو (Engine Introduction)

سامانه **تستیونو (Testino)** یک پلتفرم جامع، مدرن و آفلاین‌محور (Offline-First) برای طراحی آزمون، شبیه‌سازی دقیق، تحلیل تشریحی و ارزیابی رفتار آزمون‌دهنده در کنکور کارشناسی ارشد مدیریت است. این سامانه با تمرکز بر دقت علمی، حذف کامل خطاهای انسانی در زمان‌بندی و ثبت پاسخ، و ارائه گزارش‌های تحلیلی سه‌گامی طراحی شده است.

### ویژگی‌های کلیدی سامانه:
- **موتور آزمون هوشمند (Session Player)**: پشتیبانی کامل از حالت‌های زمان‌دار، بی‌پایان (پیوسته)، بازخورد آنی (مطالعه تعاملی) و مرور هوشمند.
- **تایمر اختصاصی و مانیتورینگ زنده**: پیگیری زمان فعال روی هر سؤال، مکث هوشمند هنگام سوییچ تب و جلوگیری از انحراف داده‌های آماری.
- **ثبت درجه اطمینان پاسخ (Confidence Tracking)**: ثبت وضعیت‌های «مطمئن»، «با شک» و «حدس زدم» همراه با شبیه‌سازی نمره در صورت عدم پاسخ به سوالات شک‌دار.
- **سیستم ورود سؤالات استاندارد (Import Engine v1.0)**: پشتیبانی از اسکیما رسمی `Testino Import Envelope` برای ورود آنی صدها سؤال با ساختار چندرسانه‌ای، فرمول‌های ریاضی و متون اشتراکی.

## ۲. معماری فنی و پشتهٔ فناوری (Architecture & Tech Stack)

تستیونو بر پایهٔ معماری توزیع‌شده محلی و با اصل اولویت عملکرد بالا توسعه یافته است:

- **فریم‌ورک رابط کاربری**: Next.js 15 (App Router) + React 19 + TypeScript
- **سیستم طراحی و استایل**: Tailwind CSS v4 بر پایهٔ الگوهای نئوبروتالیسم (Neo-Brutalism) به همراه آیکون‌های وکتور `lucide-react`
- **پایگاه داده و ذخیره‌سازی محلی**: SQLite Worker مبتنی بر WASM و OPFS با قابلیت کش محلی و کارکرد ۱۰۰٪ آفلاین
- **همگام‌سازی ابری و احراز هویت**: یکپارچه‌سازی با Supabase Auth و Database جهت پشتیبان‌گیری اختیاری و اشتراک ابری
- **رندرینگ محتوای غنی و فرمول‌ها**: KaTeX جهت رندر بلادرنگ فرمول‌های ریاضی، ماتریس‌ها و جداول مقایسه‌ای
- **مدیریت وضعیت و کش سرور**: TanStack React Query v5

## ۳. مدیریت و تعامل هوشمند با سوالات درک مطلب و متون اشتراکی زبان (Language & Passage Management)

یکی از قابلیت‌های اختصاصی تستیونو، معماری پیشرفته مدیریت سوالات گروهی و متون اشتراکی (Reading Comprehension & Cloze Test) در درس زبان عمومی و تخصصی است:

- **فصل‌بندی سه‌گانه استاندارد زبان**: در این درس، فیلد `chapter` منحصراً به سه دسته استاندارد زیر محدود می‌شود:
  1. `Vocabulary` (واژگان)
  2. `Cloze Test` (کلوزتست)
  3. `Reading Comprehension` (درک مطلب)
- **مدیریت متون اشتراکی (Groups Array)**: متن اصلی ریدینگ یا کلوزتست در سطح ریشه JSON و در آرایه `groups` تعریف می‌شود تا از تکرار متن در تک‌تک سوالات جلوگیری شود.
- **پنل ریدینگ با قابلیت سنجاق (Pinned Passage)**: در محیط آزمون، متن ریدینگ به همراه نوار دسترسی سریع به سوالات آن نمایش داده شده و کاربر می‌تواند متن را در بالای صفحه سنجاق کند تا هنگام پیمایش سوالات، متن همواره در دید باقی بماند.

## ۴. تجمیع و ادغام درصدی دروس در کنکور کارشناسی ارشد مدیریت (Subject Merging & Weighted Scoring)

در کنکور کارشناسی ارشد مدیریت، دروسی مانند «ریاضی و آمار» یا «اقتصاد خرد و کلان» ممکن است در کارنامه به صورت یک درصد تجمیعی با ضرایب مشخص محاسبه شوند. تستیونو این امکان را به صورت کاملاً تعاملی فراهم کرده است:

- **تعریف گروه‌های تجمیعی**: کاربر می‌تواند در بخش تنظیمات پروفایل و هدف‌گذاری، چندین درس را در یک «گروه نمره» قرار دهد.
- **محاسبه میانگین موزون**: درصد نهایی درس تجمیعی بر اساس وزن هر درس (تعداد سوالات یا ضریب مشخص‌شده) به فرمول زیر محاسبه می‌گردد:
  $$\text{Merged Percentage} = \frac{\sum (\text{Score}_i \times \text{Weight}_i)}{\sum \text{Weight}_i}$$
- **انطباق هوشمند با کارنامه رسمی**: نمودارها، تارگت‌های ترازی و گزارش‌های رتبه و انحراف معیار بر اساس دروس تجمیع‌شده به‌روزرسانی می‌شوند.

## ۵. راهنمای راه‌اندازی، توسعه، تست و بیلد نسخه تولیدی (Setup, Development & Build Guide)

### پیش‌نیازها:
- Node.js نسخه 20 یا بالاتر
- npm یا pnpm

### راه‌اندازی محیط توسعه:
```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه روی پورت ۳۰۰۰
npm run dev
```

### بررسی کیفیت و استانداردهای کد:
```bash
# اجرای لینتر و اعتبارسنجی سینتکس
npm run lint

# اجرای تست‌های واحد
npm test
```

### ساخت نسخه تولیدی (Production Build):
```bash
# کامپایل و بیلد بهینه‌شده
npm run build

# اجرای سرور نسخه بیلد شده
npm start
```
